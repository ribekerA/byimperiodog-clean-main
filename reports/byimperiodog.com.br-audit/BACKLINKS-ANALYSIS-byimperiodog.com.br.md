# Backlinks — byimperiodog.com.br (17/11/2026)

**Fontes:** Common Crawl (grafo de domínios cc-main-2026-aug-sep-oct), busca na web e DNS.

**Sem dados de Moz, Bing Webmaster ou Ahrefs:** não há chave configurada em `~/.config/claude-seo/backlinks-api.json`. Por isso este relatório não tem contagem de domínios de referência nem texto âncora.

## Situação

| Métrica | Valor | Confiança |
|---|---|---|
| Presente no Common Crawl | Sim | Alta |
| PageRank / centralidade harmônica (Common Crawl) | Abaixo do limite de ranking: o domínio é pequeno demais para entrar na lista | Alta |
| Perfis próprios que linkam | Instagram, Facebook, YouTube, TikTok, Pinterest, Flickr (desde 2017) | Alta |
| Links editoriais (imprensa, blogs, entidades) | Nenhum encontrado na busca | Média |

Leitura: a autoridade de links é baixa. O site ganha posição pelo conteúdo e pela relevância local, não por links. Isso combina com a posição média 5,9 em buscas de cauda média e a dificuldade nas buscas mais disputadas.

Os anúncios já apontaram para dois desses domínios (ver o relatório do Ads). Qualquer link que eles juntaram em anos se perdeu: quem segue o link encontra erro.

**Se os domínios ainda estiverem no seu nome**, ou puderem ser registrados de novo, o maior ganho de links disponível é apontá-los para o .com.br com 301 página a página (por exemplo, a página de Bragança Paulista para `/lulu-da-pomerania-braganca-paulista`). Basta conferir no registro.br quem detém cada um. Se outra pessoa registrou, não há o que fazer além de não divulgar mais esses endereços.

## Ações

1. **Alta:** conferir no registro.br a posse dos três domínios; se recuperáveis, configurar o 301 para as páginas equivalentes.
2. **Alta:** cadastrar o site no Bing Webmaster Tools, que importa do Search Console em um clique. Dá a lista de links que o Bing conhece e é a chave que destrava a próxima análise.
3. **Média:** garantir o link do site na bio de cada perfil social. Já existe em alguns; o Flickr de 2017 provavelmente aponta para um domínio antigo.
4. **Média:** pedir à CBKC ou ao clube da raça a inclusão na lista de criadores, se houver lista pública com link.
5. **Baixa:** depois disso, criar uma chave gratuita da Moz (2.500 linhas/mês) para ter domínios de referência e âncoras.
